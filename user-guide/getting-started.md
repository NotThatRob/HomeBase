# Getting Started

## Sign In

Open HomeBase in your browser and sign in with your username and password.

If this is the first run of a new installation, HomeBase may guide the first
admin user through onboarding before showing the main dashboard.

## First-Run Wizard

The wizard helps create the first asset so the household starts with useful
data instead of an empty app.

During the wizard, add:

- Asset name
- Category
- Vehicle details, if the asset is a vehicle
- Any useful starting information such as location, purchase date, or mileage

## Dashboard

The dashboard is the main landing page after sign-in. Use it to:

- Add a new asset
- Log fuel quickly
- Jump into service logging or tasks
- See upcoming and overdue maintenance
- Review monthly, yearly, and all-time spend cards
- See recent activity

## Basic Workflow

For most items, the normal flow is:

1. Add the asset.
2. Upload important documents.
3. Log service records when work is done.
4. Add recurring costs if the asset has ongoing expenses.
5. Add maintenance tasks for future work.
6. Review the asset detail page over time.

For vehicles, add fuel logs from the dashboard or top bar when you are at the
pump.

## Good First Assets

Good candidates for HomeBase are things that have documents, service history,
warranties, recurring expenses, or maintenance schedules:

- Cars
- Bikes
- Appliances
- HVAC systems
- Computers and network gear
- Furniture with warranty or purchase records

## Tips

- Use clear names, such as `Honda CR-V` or `Carrier Central HVAC`.
- Add a photo when it helps identify the item.
- Use locations for things stored in different rooms, garages, or properties.
- Add serial numbers for appliances, electronics, and equipment.
