# Assets and Inventory

An asset is anything you want to track in HomeBase. Assets are the center of the
app: documents, service records, maintenance tasks, recurring costs, and fuel
logs all belong to an asset.

## Add an Asset

1. Go to **Inventory**.
2. Select **New Asset**.
3. Enter the name and category.
4. Add optional details such as make, model, year, location, purchase date, and
   purchase price.
5. Add a photo if useful.
6. Save the asset.

## Asset Categories

HomeBase supports these categories:

- Vehicle
- Appliance
- Home system
- Tech
- Furniture
- Other

Choose the category that best matches how you will maintain the item. Vehicle
assets unlock vehicle-specific fields and fuel logging.

## Vehicle Details

When an asset category is **Vehicle**, HomeBase can track:

- VIN
- License plate
- Current mileage
- Fuel type
- Insurance information

Current mileage is useful for maintenance tasks and fuel logs. Fuel logs can
update the current mileage when an odometer value is provided.

## Asset Detail Page

Open any asset from the inventory to see its detail page. This page includes:

- Photo and identifying information
- Purchase price and purchase date
- Vehicle specifications, if applicable
- Cost of Ownership
- Fuel log, for vehicles
- Components
- Documents
- Service history
- Recurring costs
- Maintenance tasks
- Notes

## Edit an Asset

1. Open the asset.
2. Select **Edit Asset**.
3. Change the fields you need.
4. Save the changes.

## Retire an Asset

Retiring hides an asset from the default inventory view without deleting its
history.

1. Open the asset.
2. Select **Retire**.
3. Confirm the action.

Use this for items you sold, replaced, donated, or no longer actively manage.

## Shared and Personal Assets

HomeBase supports two visibility modes:

- **Shared**: visible to the household.
- **Personal**: visible only to the person who created it.

Use personal visibility for items that should not appear in another user’s
inventory, dashboard totals, or search results.

## Components

Components are tags for parts of an asset, such as brakes, tires, oil, filter,
compressor, or battery.

Use components when you want service records, documents, or maintenance tasks to
refer to a specific part of an asset.
