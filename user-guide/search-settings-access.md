# Search, Settings, and Access

## Search

Use the search box in the top bar to find information across HomeBase.

Search can help find:

- Assets
- Service records
- Documents

Good searches include:

- Asset names, such as `Honda`
- Vendors, such as `Costco`
- Document titles, such as `manual`
- Service terms, such as `brake`

## Dashboard Recent Activity

Recent activity shows newly logged service records and uploaded documents across
assets you can access.

Personal assets owned by another user are not included.

## Settings

Use **Settings** for account and admin tasks.

Depending on your role, settings may include:

- Profile updates
- Password changes
- Two-factor authentication setup
- Admin-created users
- Notification timing preferences

## Two-Factor Authentication

Two-factor authentication is optional. When it is on, HomeBase asks for your
password first, then asks for a code from an authenticator app.

To turn it on:

1. Open **Settings**.
2. Find **Security**.
3. Select **Set Up Two-Factor**.
4. Scan the QR code with an authenticator app, or type the setup key manually.
5. Enter the 6-digit code from the app.
6. Save the recovery codes somewhere private.

Recovery codes are for emergencies, such as losing your phone. Each code works
once. HomeBase shows them only when they are created.

## User Roles

HomeBase is designed for a small household.

Common roles:

- **Admin**: can manage users and household setup.
- **User**: can use the app for shared and personal assets.

## Visibility

Assets can be shared or personal.

### Shared

Shared assets are visible to the household. They can appear in:

- Inventory
- Dashboard totals
- Search
- Maintenance views

### Personal

Personal assets are visible only to the creator. They do not appear in another
user’s:

- Inventory
- Dashboard totals
- Search results
- Activity feed

## Editing and Ownership

Some actions require ownership or admin access. If you can view an asset but
cannot change it, the asset may be shared but owned by another user.

## Retired Assets

Retired assets are hidden from the default inventory view. Use the retired
filter when you need to view assets that were sold, replaced, donated, or
archived.

Retiring an asset does not delete its history.

## Security Tips

- Do not share your password.
- Use a strong admin password.
- Keep private assets marked personal.
- Avoid uploading files that do not belong in household records.
- Change default credentials before any non-local deployment.
