# Documents, Service, and Maintenance

HomeBase keeps records attached to the asset they belong to. Use documents for
files, service records for completed work, and maintenance tasks for future work.

## Documents

Documents are files linked to an asset. They can also be linked to a specific
service record.

Good documents to upload:

- Manuals
- Receipts
- Invoices
- Warranty documents
- Photos
- Inspection reports
- Registration paperwork

### Upload a Document

1. Open the asset.
2. Find the **Documents** section.
3. Add or upload a document.
4. Choose a document type.
5. Save it.

### View or Download a Document

Open the asset and select the document from the **Documents** section. HomeBase
stores file metadata in the database and serves the file through the app.

## Service Records

Service records are completed work. Use them for repairs, maintenance, upgrades,
inspections, or other work already done.

Examples:

- Oil change
- Brake inspection
- HVAC repair
- Dishwasher pump replacement
- Laptop battery replacement

### Log Service

1. Open the asset.
2. Select **Log Service**.
3. Enter the title and service date.
4. Add cost, vendor, category, and notes as needed.
5. Attach receipts or invoices if you have them.
6. Save the record.

For vehicles, you can also add mileage at service.

## Components on Service Records

If the asset has components, select the components that the service applies to.
This makes it easier to filter history later.

Example: for a brake job, tag the service record with `brakes`.

## Maintenance Tasks

Maintenance tasks are future or recurring work that needs to be tracked.

Schedule types include:

- One-time tasks
- Calendar-based intervals
- Usage-based intervals, such as mileage

### Add a Maintenance Task

1. Open the asset.
2. Find the **Maintenance Tasks** section.
3. Add a task.
4. Set the due date, interval, priority, and any usage trigger.
5. Save it.

### Complete a Task

When work is done, mark the maintenance task complete. If the task corresponds
to real work, create or complete it with a service record so the cost and notes
are preserved in history.

## Dashboard Maintenance

The dashboard shows overdue and upcoming maintenance so you do not need to open
each asset to see what is due.

## Email Reminder Plumbing

HomeBase includes reminder plumbing and per-user digest time settings. Actual
email delivery depends on production email configuration.
